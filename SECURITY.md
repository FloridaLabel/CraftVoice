# Sicherheitsmeldungen

Keine Zugangsdaten, Audioaufnahmen, Transkripte oder fremden Feldinhalte in öffentliche Issues einstellen. Verwende neutrale Beispiele.

Vor der Veröffentlichung muss ein privater Meldeweg eingerichtet werden (beispielsweise GitHubs private Sicherheitsmeldungen). In diesem lokalen Entwurf existiert noch kein öffentlicher Repository-Meldeweg. Eine Supportadresse oder aktivierte Meldefunktion wird deshalb hier nicht vorgetäuscht.
