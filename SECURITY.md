# Sicherheitsmeldungen

Keine Zugangsdaten, Audioaufnahmen, Transkripte oder fremden Feldinhalte in öffentliche Issues einstellen. Verwende neutrale Beispiele.

Sicherheitslücken mit vertraulichen Details benötigen einen privaten Meldeweg. Falls das Repository „Report a vulnerability“ anbietet, nutze diese Funktion. Eine separate Sicherheitskontaktadresse ist hier nicht dokumentiert. Falls kein vertraulicher Kanal angeboten wird, veröffentliche keine ausnutzbaren Details oder privaten Beispieldaten in einem Issue.
